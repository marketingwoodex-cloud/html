# Features — Woodex Live P22

## Website
v26 design (Plus Jakarta Sans, cream/white), Builder v3 (pages, header/footer global, media WebP), SEO 98, blog/insights, contact map, lead forms (Turnstile + honeypot + rate limit), one chat button (Chat / WhatsApp / Telegram), voice notes, EN/UR replies.

## Admin v2 (roles)
| Role | Access |
|---|---|
| Master | Everything, users, restore |
| Manager | All except users/restore; changes need Master approval |
| Developer | Website, SEO, settings |
| Sales | CRM, leads, quotes, inbox |
| Support | Inbox, project updates |

## Modules
- **CRM**: leads (New→Contacted→Site visit→Quote→Won/Lost), CSV import, follow-ups, bookings.
- **Quotations/Invoices**: WI-10100 / WF- series, A4 PDF.
- **Inbox**: website chat + WhatsApp + Telegram in one place, AI auto-reply with team takeover, quick answers, training screen.
- **Telegram**: QR connect, team alerts as DM, reply from Telegram to customer, fallback button when WhatsApp is down.
- **WhatsApp hub**: Cloud API, templates, broadcast, project updates (EN+UR).
- **Social media**: FB, IG, LinkedIn, Google Business — planner, scheduled posts, comments, articles auto-draft posts.
- **SEO**: SEO manager, AI articles (score 70+), **SEO agent** (scan → AI fixes → approve) with Claude / Codex / Hermes / local AI.
- **Speed dashboard, backups, activity log, approvals, notifications** (bell, push, sound, email).
